FIND_IN                                      *find_in*

find_in.nvim is a self-contained file finder for Neovim 0.11 or newer. It
requires ripgrep (rg).

SETUP                                           *find_in-setup*

    require("find_in").setup({})

The default search root is |getcwd()|. Configuration may be passed to setup:

    require("find_in").setup({
      initial_dir = "cwd", -- "cached" or a path are also accepted
      persistence = { enabled = true },
      ripgrep = {
        binary = "rg", hidden = false, follow_symlinks = true,
        respect_gitignore = true, globs = { "!.git/*" },
        additional_args = {},
      },
      ui = { width = 0.7, height = 0.6, border = "rounded", icons = true },
    })

COMMANDS                                        *find_in-commands*

:FindIn [path]       Open at CWD or at path.
:FindInCached        Open at the saved directory.
:FindInSetDir [path] Save path and open there; prompts if omitted.
:FindInCwd           Open at CWD.
:FindInResetCache    Clear the saved directory.

Paths without a root are relative to $HOME. Tilde and absolute paths are
accepted. The cache is stored under stdpath("state")/find_in/cache.json.

LUA API                                          *find_in-api*

    local find_in = require("find_in")
    find_in.open(opts)
    find_in.open_cached(opts)
    find_in.set_dir(path_or_opts)
    find_in.open_cwd(opts)
    find_in.reset_cache()
    find_in.get_active_dir()
    find_in.get_cached_dir()

The directory query functions return { rel = "...", abs = "..." }.
The last 10 paths added with |:FindInSetDir| or the picker are persisted in the
cache. In the picker, |<C-a>| opens a chooser for these paths and an
"Add directory…" entry. Adding a directory makes it active and displays its
files, while adding it to recent paths only; it does not change the bookmarked
cached directory. Use |<C-d>| to bookmark the active directory. |<C-c>| switches
directly to the bookmarked cached directory.

PICKER                                         *find_in-picker*

Type in normal mode to filter the list; no insert-mode prompt is needed.
Queries use fuzzy matching by default and rank tighter, earlier matches
higher. Prefix a query with ' for an exact substring, ^ for a prefix match,
or * to force fuzzy matching. Append $ for a suffix match. <C-u> clears the
query and Backspace deletes its last character. The top border shows the
query and active directory; the bottom border shows the current match index,
match count, and total file count.

Use j/k or arrow keys to select, Enter to open, and q or Escape to close.
Other actions include <C-v> for a vertical split, <C-x> for a horizontal
split, <C-t> for a tab, <C-c> for cached directory, <C-a> to choose a recent
directory or add one, <C-.> for CWD, <C-d> to bookmark, and <C-r> to rescan.
Press <C-/> to show the in-picker keymap help. Press it again to return to
the file list. The help screen reflects configured mappings.

All mappings can be overridden with the |find_in-setup| mappings table.
